## 特殊牌速查

| 牌 | 效果 |
| --- | --- |
| {{♣4}} | 迴轉：出牌順序反過來 |
| {{♦5}} | 指定：你選下一位是誰 |
| {{♥10}} | +10 或 −10 |
| {{♣J}} | Pass：總數不變 |
| {{♦Q}} | +20 或 −20 |
| {{♥K}} | 總數直接變 99 |
| {{♠A}} | 總數歸零 |

## 新手攻略

1. **保命牌留到 90 以上**：4、5、J、K、♠A、10、Q 在總數低時用，等於浪費。
2. **總數低時先出一般牌**：一般牌只能加，越晚越難出。
3. **K 是攻擊牌**：把總數推到 99，下一位手上沒保命牌就爆掉。
4. **5 指定手牌最少的人**：他的選擇少，比較容易被逼爆。
