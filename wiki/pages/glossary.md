牌桌上常聽到的說法，依注音順序排列。

| 名詞 | 意思 | 出現在 |
| --- | --- | --- |
| Pass | 這回合不出牌，讓給下一位 | [[big-two|大老二]]、[[bluff|吹牛]] |
| 蓋牌 | 沒牌可接時，挑一張手牌面朝下放著，最後算罰分 | [[sevens|排七]] |
| 抓 | 懷疑上一個人說謊，翻開他剛出的牌 | [[bluff|吹牛]] |
| 首家 | 一輪裡第一個出牌（或宣告）的人 | [[big-two|大老二]]、[[bluff|吹牛]] |
| 下莊 | 手牌出完、安全離開牌局 | [[old-maid|抽鬼牌]] |
| 爆掉 | 99 裡沒有任何牌能出而不超過 99，出局 | [[ninety-nine|99]] |
| 迴轉 | 出牌順序反過來（順時針 ↔ 逆時針） | [[ninety-nine|99]] |
| 指定 | 指定任意一位玩家接下去出牌 | [[ninety-nine|99]] |
| 葫蘆 | 三張同點數 + 一對 | [[big-two|大老二]] |
| 鐵支 | 四張同點數 + 任一張 | [[big-two|大老二]] |
| 同花順 | 同花色的順子，大老二最大的牌型 | [[big-two|大老二]] |
| 牌局編號 | 洗牌用的種子，同編號 = 同一副牌 | 所有遊戲，見 [[card-basics|撲克牌基礎]] |
