# 牌搭子 Card Buddies

找朋友圍一桌，或叫電腦來湊人數——打開就能玩的撲克牌遊戲大廳。

# 目前的牌桌

| 遊戲 | 人數 | 特色 |
| --- | --- | --- |
| 21 點 | 1–5 | 和電腦莊家對決，5 局比籌碼 |
| 大老二 | 2–4 | 台灣聚會經典，支援單張、對子、順子、葫蘆、鐵支、同花順 |
| 排七 | 3–6 | 從 7 往兩邊接龍，沒牌就得蓋牌扣分 |

每個座位都能選「好友」或「電腦」（簡單／普通／困難）。選了好友座位就會產生邀請連結，傳給朋友後，大家用自己的手機或電腦一起玩（透過 PeerJS 點對點連線，不需要註冊）。

# 專案重點：AGENTS.md

不只是一個網頁，而是一套**可以持續擴充的規則**。[`AGENTS.md`](AGENTS.md) 定義了：

- 專案目的、技術限制、網頁風格與共用元件
- 目錄結構與命名規則
- 遊戲的「規則模組介面」與「畫面介面」
- 新增遊戲的 SOP 與驗證方式
- AI 修改專案時必須遵守的規則

只要對 AI 說「依照 AGENTS.md 新增一個抽鬼牌遊戲」，它就能用同一套架構做出新的牌桌，大廳也會自動出現新卡片。

# 本機執行

```bash
python3 -m http.server 8000
# 打開 http://localhost:8000
```
# 檢查工具

```bash
node tools/check.js            # 檢查檔案結構是否符合 AGENTS.md
node tools/simulate.js         # 讓電腦互打，每個遊戲 200 局，確認規則不會卡死
```
